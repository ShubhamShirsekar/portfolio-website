## Overview

A content-based recommender built for the Machine Learning I assessment. For each user, a One-Class SVM learns the audio-feature profile of the tracks they already listen to, then flags new tracks that fall inside that profile as recommendations.

---

## Problem Statement

Generic music recommendations often miss personal preferences. This project creates a personalized recommender that:
- Learns each user's taste from the tracks they already have (positive examples only)
- Uses audio features for content-based matching

---

## Data

- **Source**: Provided as a part of ML-I assesment
- **Features**: 22 audio features per track
- **Size**: 3600 unique tracks

---

## Approach

1. **Feature Engineering**
   - Normalized and scaled features
   - Introduced derived features

2. **Model**
   - One-Class SVM per user, trained only on that user's tracks
   - New tracks inside the learned boundary are recommended

3. **Evaluation**
   - System Recall for each User
   - Average System Recall: 86%

---

## Results & Impact

- Average System Recall: 86%

---

## Key Learnings

- One-Class SVM fits recommendation when only positive examples (a user's own tracks) are available
- Feature correlation analysis reveals interesting musical patterns
